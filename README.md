# alexkads.github.io

Root GitHub Pages site for [alexkads](https://github.com/alexkads): a showcase of the
open-source projects that have their own site on this domain —
[MAC-LIMPO](https://alexkads.github.io/MAC-LIMPO/),
[VintageLightbox](https://alexkads.github.io/VintageLightbox/) and
[Open Cleaner RN](https://alexkads.github.io/open-cleaner-rn/).

`robots.txt`, `favicon.ico` and the root `sitemap.xml` must live here: crawlers only read
them from `https://alexkads.github.io/`, and the favicon is shared by every project site
on the domain (hence the neutral "AK" monogram).
