# alexkads.github.io

Root GitHub Pages site for [alexkads](https://github.com/alexkads). It introduces
[MAC-LIMPO](https://github.com/alexkads/MAC-LIMPO) — a free, open-source disk cleaner and
disk space analyzer for macOS — whose documentation lives at
<https://alexkads.github.io/MAC-LIMPO/>.

`robots.txt` and `favicon.ico` must live here, at the root of the domain: crawlers only
read them from `https://alexkads.github.io/`, not from project sites.
