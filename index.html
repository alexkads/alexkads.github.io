MAC-LIMPO

Disk cleaner & disk space analyzer for macOS

Frees disk space taken by Xcode, simulators, Docker, node_modules and 40+ developer caches from the menu bar, and maps every gigabyte in a 2D/3D treemap. A free alternative to CleanMyMac and DaisyDisk.

VintageLightbox

Photo editor in Rust

Import, organize, cull, develop and deliver — a free, Lightroom-style photo workflow written in Rust with a native GPU interface. Made for the Recordar Fotos studio in Gramado and Canela.

Open Cleaner RN

Dev environment cleaner for React Native

Cleans caches and build artifacts of React Native and cross-platform projects to free disk space and keep the development workflow fast. A desktop app built with Rust and Tauri.
